## 功能 1：主题/色彩系统（提交 3b1bc6d，已推送）
- `src/styles/theme.css`：PRD §4.2 全套 CSS 变量（浅色 `:root` + 深色 `[data-theme="dark"]`），含背景层级、边框、文字、语义色、8 色 lane 调色板、字体栈。
- `src/styles/index.css`：Tailwind 4 入口，`@theme inline` 将 CSS 变量映射为工具类（`bg-surface`、`text-fg-secondary`、`border-border-subtle`、`bg-lane-1` 等）；`@custom-variant dark` 支持 `[data-theme="dark"]`；基础样式（13px 字号、8px 细滚动条、`#root` 铺满）。
- `src/store/theme.ts`：Zustand + persist（localStorage key `gitvista-theme`），mode = light/dark/system，`applyTheme` 写 `document.documentElement.dataset.theme`，监听系统主题变化。
- `vite.config.ts`：注册 `@tailwindcss/vite` 插件（原模板缺失，导致 `@theme` 未编译，已修复）。
- `index.html`：lang 改 zh-CN，title 改 GitVista。
- `pnpm build` 通过。
