## 功能 8：工作区 stage/diff/commit（提交 4578191 + 04922cb，已推送）
- Rust `src-tauri/src/commands/workdir.rs`（5 个命令）：
  - `get_worktree_status`：分 staged（head_to_index delta）/unstaged（index_to_workdir delta）/conflicts；status 字母映射 A/M/D/R/C/T（Untracked→A）。
  - `stage_files`：`index.add_path` 批量。
  - `unstage_files`：HEAD tree 有该文件 → 复用 index entry 改 id 为 HEAD blob 再 `index.add`；HEAD 无 → `index.remove_path`。
  - `get_diff(path?, staged)`：staged 用 `diff_tree_to_index`（无 HEAD 时 old_tree=None 即空树），unstaged 用 `diff_index_to_workdir`；pathspec 过滤单文件；`DiffFormat::Patch` 收集字符串 + 统计 +/- 行数。
  - `commit_changes(message, amend)`：校验非空；write_tree；user.name/user.email 从 repo config 读（未配置报中文错误）；amend 时父为 HEAD 的父；返回新 oid。
  - API 坑：`StatusEntry` 方法是 `head_to_index()`/`index_to_workdir()`（非 index()/workdir()），`DiffFile::path()` 返回 `&Path`；diff.print 回调返回 `bool` 非 Result；`Commit::parents()` 迭代器 Item=Commit 可直接 collect。
- ⚠️ 重大教训：不要用 PowerShell `Get-Content/Set-Content` 处理含中文的 UTF-8 文件（按 GBK 读写会损坏编码），一律用 edit/write 工具；曾因此重写 workdir.rs。
- 前端：
  - `src/store/shell.ts`：加 `drawerOpen/toggleDrawer`（persist）。
  - `src/components/workbench/ChangesDrawer.tsx`：底部抽屉（42vh/收起 39px，200ms ease-out 过渡）；Unstaged/Staged 分区列表（状态字母着色 + hover 单文件 stage/unstage + 全部暂存/取消）；冲突数警示；错误内联显示；CodeMirror 提交框（64px，light/dark 主题跟随）+ Amend 复选 + 提交按钮（staged 空或消息空禁用）；操作后 invalidate worktree/diff/commits + refreshRepo。
  - `src/components/workbench/DiffView.tsx`：unified diff 着色（+++ 文件头灰、@@ hunk 蓝底、+ 绿底、- 红底、\\ muted），顶部显示 +/- 统计。

## 用户实测反馈修复（提交 c66e695 + c7c7784，已推送）
1. **TitleBar 右上角设置按钮无效**：按钮没绑 onClick → 加 `openSettings`（c66e695）。
2. **Graph 提交信息左侧 lane 区空白**（GraphView.tsx，c7c7784）：
   - 根因 A：`useEffect [draw, themeMode]` 只在 draw 引用变时执行，而 virtualizer 首次 items 经异步 observer 就绪，首画时空数组，之后无 scroll/hover 永不重画 → 改为**无 deps 的 useEffect 每次 render 后 draw**（items setState 必触发 re-render）。
   - 根因 B：canvas `absolute top-0` 在 overflow 滚动容器内**随内容滚动**，绘制却用 `item.start - scrollTop`（双重补偿）→ 改为直接 `item.start`（内容坐标）。
   - scroll 重绘改为 ResizeObserver（内容坐标绘制不随 scroll 变化，items 更新走 render）；`themeMode` 改为裸订阅触发 re-render。
   - **坐标系教训**：overflow 容器内 absolute 元素坐标 = 内容坐标，与 scrollTop 无关。
3. 排查手段教训：不可抢占用户屏幕截屏（SetForegroundWindow/topmost 均干扰用户）；用户截图 + 静态代码分析更可靠。
4. 待确认：曾出现"选择仓库目录"系统对话框疑似启动时自动弹出（未在代码中找到自动触发点，可能为用户手动操作残留）；若再次复现需排查。
